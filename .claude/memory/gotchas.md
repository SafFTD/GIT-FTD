```markdown

**Where it bit us:** <Bug B<N> or feature F<N>>
**Symptom:** <What you observe — be specific>
**Cause:** <Why it actually happens>
**How to avoid:**
- <Concrete rule / convention / check>

(Optional) **Related:** `[[anti-patterns.md#A<N>]]`
```
